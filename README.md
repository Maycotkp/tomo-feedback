# Tomo · Relatos e sugestões

Aqui você conta o que deu errado ou o que gostaria de ver no **Tomo**, o sistema de suporte para o mestre de RPG (mesas presenciais e no Discord, sem VTT). A versão atual é bem inicial, antes da alfa, e só para Android.

Este repositório **não tem código**. Serve só para receber relatos de erro, sugestões e dúvidas.

## Como relatar
1. Abra a aba **Issues** e clique em **New issue**.
2. Escolha **Relatar um erro** ou **Sugerir uma ideia**.
3. Preencha o formulário em português simples. Quanto mais detalhe, melhor.

Não coloque senhas, chaves ou dados pessoais nos relatos: esta página é pública.
